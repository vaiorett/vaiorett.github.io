使用顺序

  1. 选择图片、项目文字或主页文字。
  2. 填写中文和英文，预览后检查。
  3. 连接 GitHub 后发布，或导出更新文件。

不需要再把效果图拼成长图。现有长图可以在添加新图后移除。

项目视频 · B 站 / YouTube / 视频直链

粘贴 B 站、YouTube 或 HTTPS MP4 / WebM 直链，系统自动识别平台。YouTube 封面立即识别，B 站封面在发布后尝试自动获取；受平台限制时可上传封面。b23.tv 短链接请先打开，再复制地址栏中的完整链接。这里不上传视频文件。

画质由平台自动选择。YouTube 使用官方播放器；B 站保留官方控件并关闭弹幕；MP4 / WebM 支持点击画面暂停/继续。YouTube 登录验证与 B 站推荐无法由本站取消。希望访客直接观看、没有平台推荐，可填写自己视频的 MP4 / WebM 直链作为纯净播放版本。

修改会自动保存为本机草稿。工具和条目请每行填写一项；中英文需要分别修改，不会自动翻译。网页修改不会改动简历 PDF。
