自己更新作品与排版

这里管理的是公开作品集。完整简历请单独发给招聘方，不要上传到此网站。

图片与文字自动排版

  1. 选择项目，在“项目图片”中上传独立图片，系统自动转换 WebP。
  2. 选择“自动排版”“单列大图”“双列图库”或“图文叙述”。自动排版按图片比例安排，长图完整显示，手机使用单列。
  3. 在每张图片下填写说明和可选的中英文段落。空行分段；图文叙述会在桌面交替排列图片和说明。
  4. 拖动图片或点击上下移动，调整图文阅读顺序。可把单张图设为整行或半宽。
  5. 点击“预览未发布修改”，确认后发布。不满意时可一键恢复自动排版。

自动排版不消耗 AI 对话额度，也不会自动编写经历或翻译内容。

添加视频

  1. 进入“项目视频”，粘贴 B 站完整链接/BV 号、YouTube 链接或 HTTPS MP4/WebM 直链。
  2. YouTube 自动识别封面；B 站会尝试读取，受限时保留旧图或项目图，也可上传自己的封面。
  3. 视频标题用于管理和无障碍说明，不会额外叠在封面上或重复显示在下方。

YouTube 可能要求登录确认，B 站可能显示推荐；这些由平台控制。访客可在播放后的“⋯”中打开视频来源。希望没有平台界面时，在“纯净播放版本”填写自己视频的 HTTPS MP4/WebM 直链。普通分享网页、短期链接和含私人凭证的链接不适用。

文字、工具与新增项目

进入“项目文字 / 工具”编辑项目职责和使用工具；“主页 / 个人资料”管理品牌、自我介绍、制作领域与公开联系邮箱。中文和英文分别填写。新增项目会自动生成两种语言的详情页及首页卡片。

主题与语言

点击太阳或月亮图标选择浅色、深色或跟随系统。语言入口直接切换对应页面；字体和图标从本站加载。

发布与备份

草稿保存在当前浏览器中，发布后访客才能看到。连接 GitHub 时使用仅允许本仓库 Contents 读写的精细授权令牌；令牌只在本次页面内存中使用。网络不稳定时先导出更新包。改版前的旧草稿不会自动迁入，避免重新发布私人资料。

每次发布前的隐私检查

  • 不要填入真实姓名、手机、微信、具体任职日期、学校或工作单位。
  • 查看图片是否含姓名、地址、账号、客户标识、内部文件路径或机密批注。
  • 完整简历和私人备份保存在自己设备中；本网站不提供这些附件。
  • noindex 能减少搜索收录，但不能阻止有链接的人查看或保存。
