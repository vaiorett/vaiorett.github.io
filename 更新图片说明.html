自己更新图片与网站文字

现有 Photoshop 排版长图会继续展示。之后每张优化好的效果图都可以独立添加、替换、排序，不需要重新拼图。

切换明暗模式

页眉可以选择“跟随系统”“浅色”或“深色”。默认跟随浏览器主题；手动选择会记住，想恢复自动变化时选回“跟随系统”。

新增项目

  1. 点击左侧“＋ 新增项目”，填写中英文名称，选择分类。
  2. 在“项目文字 / 工具”填写中英文简介及真实职责，随后添加图片或视频。第一张图片自动作为封面，也可另选。
  3. 预览后点击“发布所有修改”，新项目会自动进入主页，并生成中英文详情页。

只有视频也能发布；建议补一张自己的封面图。尚未发布的新项目可点击“放弃这个未发布的新项目”。

嵌入 B 站视频

  1. 选中项目，进入“项目视频”。
  2. 粘贴完整 B 站视频链接或 BV 号，再点“添加视频”。如果是 b23.tv 短链接，先打开它，再复制地址栏的完整链接。
  3. 分别填写中英文标题，需要时调整顺序，最后发布。

访客点击后会加载官方播放器，再点击播放器里的播放键。视频如受平台、登录或网络限制，可使用“在 B 站观看”。这里不需要粘贴嵌入代码，也不上传视频文件。

修改文字与使用工具

  1. 进入“项目文字 / 工具”，左侧选择项目，修改标题、简介、个人职责、项目背景、署名、工具和工作条目。工具和工作条目每行一项。
  2. 进入“主页 / 个人资料”，修改“网站署名（原 VIOLET_KOKORO）”、姓名、首页标题、介绍、能力、经历、技能和联系邮箱。自我介绍中提到的名字可以在对应文字中修改。
  3. 切换“文字语言”，分别修改中文和英文；不会自动翻译。公共署名、邮箱和工具技能清单在两种语言共用。
  4. 点击“预览未发布修改”检查，随后点击“发布所有修改”。草稿不会自动改变公开网站。

网页文字修改不会更新简历 PDF。本管理页支持新增项目；工作经历仍编辑现有记录。

整理图片

  1. 打开网站底部的“作品管理”，选择对应项目。
  2. 点击“选择图片”逐张或批量添加，或使用已有图片下方的“替换此图”。
  3. 填写图片说明与图片描述，用上移、下移或拖拽调整顺序，再选一张作为封面。
  4. 新图加入后，可以把原来的作品长图从展示中移除。移除只影响画廊，不会删除仓库中的原始文件。

原图每张最多 32 MB，支持 JPG、PNG、WebP 和 AVIF 静态图片。添加时会自动转为 WebP，并显示转换前后大小；可选择“高清作品”“保留原尺寸”或“更小文件”。高清模式会限制普通大图尺寸，长幅排版图保留尺寸。原文件仍在你的设备上。草稿只保存在当前浏览器，换设备前请导出。

直接发布

  1. 展开“连接 GitHub”，进入 GitHub 官方授权设置。
  2. 创建精细授权令牌，资源所有者选 vaiorett，只选择 vaiorett.github.io 仓库，在 Permissions 点击 Add permissions，搜索并勾选 Contents，再把出现的权限行设为 Read and write，设置合适的到期时间。创建与保管令牌由你在 GitHub 内完成。
  3. 把令牌粘贴到管理页，点击“验证连接”。它仅在当前页面内存中使用；刷新、关闭或断开后需要重新输入。请勿把令牌放到图片、文件名、说明或聊天消息中。
  4. 点击“发布所有修改”。页面会显示本次 GitHub 提交链接。提交成功后，还需要等待 GitHub Pages 完成更新，再查看公开作品页。

如果线上有其他修改，管理页会先核对版本；发生冲突时会保留草稿并提示重新连接，不会强制覆盖。

不使用授权令牌

点击“导出更新文件”，保存 ZIP 包并解压。包中包含新的图片、文字与画廊数据、全部中英文网页及站点地图和操作说明。在 GitHub 按原路径上传全部文件，包括 en/ 中的网页，放在同一次提交中。日常也可以直接在管理页连接发布，不需要通过聊天修改。若只在本机预览，把这些文件合并到完整网站文件夹后打开首页即可。

导出的包是本次更新文件，不是完整网站；网站完整备份应另行保留。

公开内容

图片、说明、封面和公开简历会对访客可见。证书在网站中以名称、科目、日期与成绩展示，未上传证书原图。
