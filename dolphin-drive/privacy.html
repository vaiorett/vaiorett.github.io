Privacy policy

隐私政策

生效日期：2026-10-30。本说明适用于 Vaiorett 维护的个人 Dolphin Google Drive 桌面接入配置。

访问的数据与用途

在用户通过 Google 授权后，本机 rclone 使用 https://www.googleapis.com/auth/drive.readonly 权限读取 Google Drive 文件及其名称、目录、大小、修改时间等元数据，以便在 Dolphin 中列出、打开和下载文件。当前配置不申请上传、修改或删除云端文件的权限。

数据流向与存储

rclone 在用户电脑与 Google 的 API 之间直接传输数据。授权令牌和客户端配置保存在本机用户专用配置目录，文件权限限制为当前用户访问。打开文件时可能在本机产生缓存；用户主动下载的文件保存在用户选择的位置。此配置不运营集中式服务器，不将文件或令牌上传到本网站、GitHub Pages 或维护者的其他服务。

使用限制

Google 用户数据仅用于上述个人文件访问功能，不用于广告、出售、数据经纪或训练通用 AI 模型，不通过此配置与其他用户共享。Dolphin Google Drive 对从 Google API 获得的信息的使用和转移将遵守 Google API Services User Data Policy，包括其 Limited Use 要求。

保留与删除

登录令牌会保留在本机，直到用户移除配置或撤销访问。缓存由本机 rclone 管理；默认配置的缓存目标上限为 2 GB、未访问缓存的最长保留目标为 24 小时，正在使用的文件和清理时机可能影响实际保留情况。用户可以停止自动连接服务后删除本地缓存与专用配置目录。主动下载的文件需由用户自行删除。

撤销访问

用户可随时在 Google 账号的第三方连接设置 中移除 Dolphin Google Drive 的访问权限，并在电脑上停用自动连接。撤销授权不会删除 Google Drive 中的原始文件。

此说明网站

本页面由 GitHub Pages 托管，不使用分析脚本、广告或收集表单。托管服务可能按照自身政策处理常规网络请求记录。浏览此页面不授予任何网盘访问权限。Google 的服务另受其自身隐私政策约束。

联系与更新

维护者为 Vaiorett。有关此个人配置的问题，可通过 个人网站的联系入口 联系。若本配置的数据用途或授权范围变化，将相应更新本说明。
